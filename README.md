# LUTSK — Місто Волині

Мінімалістичний адаптивний інформаційний сайт про Луцьк українською мовою.

## Запуск

Це статичний сайт без збирача та залежностей. Відкрийте `index.html` у браузері або опублікуйте репозиторій через GitHub Pages.

## Публікація через GitHub Pages

1. Відкрийте **Settings → Pages** у репозиторії.
2. У розділі **Build and deployment** виберіть **Deploy from a branch**.
3. Вкажіть гілку **main** та папку **/(root)**, натисніть **Save**.
4. Після завершення розгортання сайт буде доступний за адресою GitHub Pages вашого репозиторію.

## Структура

- `index.html` — увесь сайт: семантична HTML-розмітка, адаптивні стилі та інтерактивність.
- Карта міста — OpenStreetMap.
- Візуальна схема транспортних напрямків та функціональних зв'язків агломерації — SVG.

Статистичні дані про населення наведені як оцінка станом на 01.01.2023, а не як актуальний перепис. Перелік підприємств і деякі історико-географічні відомості слід перевірити за офіційними джерелами перед використанням у формальних публікаціях.
